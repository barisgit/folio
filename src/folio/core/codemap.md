# Folio Core Domain Layer — Code Map

## 1. Responsibility

The `core/` directory is the **domain layer** of the Folio document generation engine. It implements a clean pipeline:

```
DSL Spec (Python) → Model → Render → Export
```

- **`model/`** — Immutable domain primitives (`Element`, `Page`, `Document`, `DocumentCollection`) and export configuration types.
- **`dsl/`** — The authoring DSL: element factories, text layout, styling, design tokens, and a tweak system for user-editable values. Depends on `model/`.
- **`render/`** — Converts model objects to SVG output strings. Depends on `model/`.
- **`export/`** — Converts rendered output to PNG, PDF, and IDML (Adobe InDesign) formats.
- **`layout/`** — Geometric layout helpers (`Columns`, `Grid`, `FlowColumns`) for page composition.
- **`cache.py`** — File-based cache for build artifacts and reconcile state.
- **`preview.py`** — Rasterizes SVG to PNG using Playwright, CairoSVG, rsvg-convert, or Inkscape.

## 2. Design

### 2.1 `core/model/` — Domain Primitives

| File | Classes / Types | Role |
|------|-----------------|------|
| `defs.py` | `DefNode` | Positionless SVG `<defs>` nodes (gradients, filters, clipPaths). Produced by DSL primitives (`linear_gradient`, `filter_`, `clip_path`, `svg_node`). |
| `document.py` | `ElementKind` (enum) | Discriminator for 10 concrete element types: `RECT`, `CIRCLE`, `ELLIPSE`, `TEXT`, `IMAGE`, `GROUP`, `PATH`, `POLYGON`, `POLYLINE`, `LINE`. Renderer dispatches on this enum. |
| `document.py` | `Asset` | Reference to external raster/vector asset with physical dimensions. Wrapped by `IMAGE` elements. |
| `document.py` | `TextSpan` | Nested styled text run within `TEXT` elements. Produced by `tspan`/`span`. |
| `document.py` | `Element` | Any drawable node. Fields: `kind: ElementKind`, `element_id: str`, `x_mm/y_mm`, `content`, `attrs`, `children`. |
| `document.py` | `TextMetrics` | Measured dimensions of text runs. Fields: `width_mm`, `height_mm`, `line_count`, `line_step_mm`, `truncated`. |
| `document.py` | `Page` | Top-level renderable page. Fields: `page_number`, `page_id`, `filename`, `elements`, `width_mm`, `height_mm`, `defs`, `label`, `attrs`, `extra_exports`. |
| `document.py` | `Document` | Root of multi-page document. Fields: `pages`, `defs`, `config_hash`, `metadata`, `document_id`, `export_presets`, `default_exports`. |
| `document.py` | `DocumentCollection` | Groups one or more `Document` instances for document-oriented exports (IDML, PDF). |
| `export.py` | `ExportFormat` (StrEnum) | `"svg"`, `"png"`, `"pdf"`, `"idml"`. |
| `export.py` | `ExportScope` (StrEnum) | `"page"` or `"document"` — whether a preset produces per-page artifacts or one document artifact. |
| `export.py` | `ExportPreset` | Named build target. Fields: `name`, `format`, `scope`, `viewport`, `filename_pattern`, `source`. |
| `markup.py` | `Markup` | Trusted raw SVG string wrapper. Created by `markup()`; renderer emits verbatim. |
| `result.py` | `RenderedPage` | Rendered SVG page with number, id, filename, and content string. |
| `result.py` | `RenderedDocument` | A `Document` + its rendered pages. |
| `result.py` | `BuildResult` | Top-level build output: list of `RenderedPage`, config hash, and `RenderedDocument` list. |
| `result.py` | `RenderError`, `ValidationWarning` | Exception and warning classes. |
| `result.py` | `config_digest(path: Path) -> str` | SHA-256 of source file bytes. |

**Design Pattern:** Pure immutable dataclasses with `frozen=True`. No behavior, only data. Value equality via `__eq__` generated by dataclass.

### 2.2 `core/dsl/` — Authoring DSL

| File | Key Functions / Classes | Role |
|------|------------------------|------|
| `builtins.py` | `page()`, `document()`, `collection()`, `render()` | Top-level composition functions. `page()` assembles `Page` from `Element` children. `document()` groups pages and adds export presets. `collection()` wraps one or more documents. `render()` validates and returns `DocumentCollection`. |
| `builtins.py` | Shape factories: `rect()`, `circle()`, `ellipse()`, `polygon()`, `polyline()`, `line()`, `path()`, `image()`, `text()`, `multiline()`, `wrapped_text()`, `tspan()`, `span()`, `qr()`, `rule()`, `triangle()`, `group()` | Create `Element` and `TextSpan` instances. Auto-generate stable `element_id` via `_element_id()`. |
| `builtins.py` | `Block` (dataclass) | Scoped id/coordinate helper. Methods delegate to module-level factories with auto-prefixed ids and translated coordinates. |
| `builtins.py` | `PathBuilder` (dataclass, slots) | Fluent builder for SVG path `d` strings in mm coordinates. Methods: `move_to`, `line_to`, `horizontal_to`, `vertical_to`, `curve_to`, `quad_to`, `arc_to`, `close`. |
| `builtins.py` | `TransformBuilder` (dataclass, slots) | Fluent builder for SVG `transform` strings in mm coordinates. Methods: `translate`, `rotate`, `scale`, `skew_x`, `skew_y`, `matrix`, `build`. |
| `builtins.py` | `block(prefix, at=(x, y))` | Factory for `Block` instances. |
| `builtins.py` | Text measurement: `measure_text()`, `measure_wrapped_text()` | Return `TextMetrics` without constructing `Element`. |
| `builtins.py` | Export preset factories: `svg()`, `png()`, `pdf()`, `idml()` | Return `ExportPreset` instances. |
| `builtins.py` | `TextLayoutWarning` | `UserWarning` subclass emitted when `wrapped_text` truncates. |
| `charts.py` | `chart(element_id, x_mm, y_mm, width_mm, height_mm, ...)` | Creates a `ChartHandle` for matplotlib-backed chart `Element`s (kind `IMAGE`). Supports decorator (`@handle`), context manager (`with handle as ax:`), and `from_figure(fig)` forms. PNGs cached by SHA-256 of bytes at `<spec>/.folio-cache/charts/`. |
| `charts.py` | `ChartHandle` | Rasterizes matplotlib `Figure` to PNG, wraps as `Element` via `image()`. |
| `charts.py` | `set_spec_base_dir(path)` | Records spec directory for relative PNG path resolution. |
| `composition.py` | Re-exports: `block`, `collection`, `document`, `page`, `render` | Organizational alias for `builtins`. |
| `elements.py` | Identical DSL primitives as `builtins.py` | Split boundary; currently a duplicate for organizational clarity. |
| `loader.py` | `load_dsl_module(path: Path) -> types.ModuleType` | Imports a user `build.py` spec file as an isolated module using `importlib.util.spec_from_file_location`. Sets up DSL builtins, chart cache dir, resets auto-ids, and clears spec-local cached modules so imported `theme.py`/layout modules re-execute inside the active tweak context on repeated loads. |
| `loader.py` | `default_spec_path()`, `resolve_spec_path()` | Locate `build.py` relative to cwd. |
| `loader.py` | `DslError` | Exception for load failures. |
| `schema.py` | `DocumentFactory` (Protocol) | Type hint for spec's `build()` return type. |
| `styles.py` | `TextStyle` (dataclass, frozen, slots) | Reusable text styling preset. Fields: `font_size_pt`, `font_weight`, `fill`, `fill_opacity`, `letter_spacing`, `text_anchor`, `font_family`, `font_style`. Callable — `style(id, x, y, content)` produces a `text` `Element`. Methods: `text_attrs()`, `span_attrs()`, `text()`, `span()`, `multiline()`, `wrapped_text()`, `measure_text()`, `measure_wrapped_text()`. |
| `styles.py` | `coerce_text_style(style)` | Validates and returns `TextStyle`. |
| `styles.py` | `merge_text_style_attrs(attrs, for_span)` | Merges style fields into attrs, normalizes key names. |
| `tokens.py` | Re-exports from `core.render.tokens` + `TextStyle` presets | Color palette (`ACCENT`, `INK`, `MUTED`, `WHITE`, etc.), page sizes (`A4`, `A5`, `DL`, `US_LETTER`, `ROLLUP_850x2000`), unit conversions, `STYLES` namespace with named presets (`hero`, `body`, `kicker`, `title`, etc.). |
| `tokens.py` | `extend(**colors)` | Registers additional color tokens at runtime on both `folio.dsl.tokens` and `folio.render.tokens`. |
| `tweaks.py` | `TweakDeclaration` (dataclass, frozen) | Schema for one approved tweak. Fields: `key` (dotted), `group`, `name`, `kind` (`color`, `size_pt`, `opacity`, `choice`, etc.), `default`, `mode` (`live`/`rebuild`), `label`, `min`, `max`, `options`. |
| `tweaks.py` | `TweakDiagnostic` (dataclass, frozen) | Non-fatal validation note. Fields: `severity`, `key`, `message`. |
| `tweaks.py` | `TweakValue` (class) | Wrapper around resolved tweak value. Lazy-reads from `TweakRegistry`. Supports `__str__`, `__float__`, `__int__`, `__bool__`, and arithmetic (`+`, `-`, `*`, `/`). Property: `css_var` returns `--folio-tweak-<key>`. |
| `tweaks.py` | `TweakGroup` | Frozen attribute-access view over a group of `TweakValue`s. |
| `tweaks.py` | `TweakRegistry` (dataclass) | Spec-scoped collection of declarations, resolved values, and diagnostics. Methods: `register(decl)`, `resolved(key)`, `apply_values(mapping)`, `snapshot()`. |
| `tweaks.py` | `tweak_context(registry=None)` | Context manager for `TweakRegistry` binding. Active automatically during spec load. |
| `tweaks.py` | `group(name, **members)` | Registers a named group of tweaks and returns `TweakGroup`. Members are pending declarations from helpers. |
| `tweaks.py` | Helper functions: `color()`, `size_pt()`, `size_mm()`, `opacity()`, `letter_spacing()`, `stroke_width()`, `choice()`, `preset()`, `font_choice()` | Create pending declarations consumed by `group()`. |
| `tweak_values.py` | `resolve_values_file(spec_path)` | Returns `<spec_dir>/theme.toml`. |
| `tweak_values.py` | `load_persisted_values(path)` | Parses TOML; returns `None` if file absent. |
| `tweak_values.py` | `validate_persisted_values(registry, raw, source)` | Validates persisted values against declarations. Returns `(validated, diagnostics)`. |
| `tweak_values.py` | `apply_persisted_values(registry, spec_path)` | Full orchestration: resolve → load → validate → apply → return diagnostics. |
| `tweak_values.py` | `write_persisted_values(path, registry)` | Writes deterministic TOML from registry state. Groups and members sorted alphabetically. |
| `tweak_values.py` | `TweakValuesError` | TOML parse/format errors. |

**Design Patterns:**
- **Builder pattern:** `PathBuilder`, `TransformBuilder` are fluent builders using method chaining.
- **Protocol pattern:** `DocumentFactory` for static type checking of spec signatures.
- **Context manager:** `tweak_context()` for thread-safe registry binding via `contextvars.ContextVar`.
- **Decorator + context manager:** `ChartHandle` supports three usage shapes.
- **Frozen dataclass:** All model types are immutable.
- **Lazy resolution:** `TweakValue` reads from registry on access, supporting persistence applied after declaration.

### 2.3 `core/render/` — SVG Rendering

| File | Key Functions | Role |
|------|---------------|------|
| `pipeline.py` | `build_pages(dsl_module, config_dir, output_dir, mode)` | Top-level entry. Loads module, calls `render_collection`, optionally writes pages. |
| `pipeline.py` | `render_collection(collection, config_dir, source_path, mode)` | Renders all documents in a collection. Returns `BuildResult`. |
| `pipeline.py` | `render_document(document, config_dir, source_path, mode)` | Renders one document's pages to `RenderedPage` list. |
| `pipeline.py` | `_render_document_pages(document, config_dir, mode)` | Validates document, renders each `Page` via `_render_page`. |
| `pipeline.py` | `_render_page(page, config_dir, document_defs, mode)` | Renders one page: opens SVG, emits defs blocks, renders each element, closes. |
| `pipeline.py` | `_render_element(element, config_dir, mode)` | Dispatches on `element.kind` (10 cases). Calls primitive renderers from `primitives.py`. Handles `TweakValue` unwrapping via `_format_live_eligible_value`. |
| `pipeline.py` | `_render_text(element, mode)` | Handles `TEXT` elements with style merging and live-eligible attribute routing. |
| `pipeline.py` | `_render_def_node(node, config_dir, mode)` | Recursively renders `DefNode` (including nested elements). |
| `pipeline.py` | `_defs_block(defs, config_dir, mode)` | Assembles SVG `<defs>` section. |
| `pipeline.py` | `_normalize_svg_attrs(attrs, mode)` | Converts `_mm`/`_pt` suffixes, normalizes names, handles `TweakValue` wrappers. |
| `pipeline.py` | `_format_live_eligible_value(value, mode)` | In `build` mode, unwraps `TweakValue` to concrete primitives. In `playground` mode, live-mode tweaks on allow-listed presentation attrs emit `var(--folio-tweak-..., fallback)`. |
| `pipeline.py` | `_format_live_css_value(kind, value)` | Formats CSS-variable fallbacks with units for numeric live attrs (`size_pt`/`letter_spacing` → `pt`, `size_mm` → `mm`) so SVG `font-size` and spacing update correctly. |
| `pipeline.py` | `collection_from_module(dsl_module)` | Extracts `DocumentCollection` from `build()`, `collection`, or `document` module attributes. |
| `pipeline.py` | `document_from_module(dsl_module)` | Single-document shortcut. |
| `pipeline.py` | `validate_document(document)` | Validates pages, export presets, element ids, and warns on non-token hex colors. |
| `pipeline.py` | `effective_export_presets(document)`, `export_preset_map(document)`, `resolve_export_targets(document, requested)` | Export preset resolution and validation. |
| `pipeline.py` | `_validate_export_preset_cycles(presets)` | Detects dependency cycles in preset graph. |
| `pipeline.py` | `write_pages(result, out_dir)` | Writes `RenderedPage` content to filesystem. |
| `pipeline.py` | `RenderMode = Literal["build", "playground"]` | Controls live-eligible attribute formatting. Build mode is authoritative/concrete; playground mode may emit CSS custom properties for safe live edits. |
| `primitives.py` | `m(value_mm)` | Converts mm to pt (internal SVG units). |
| `primitives.py` | `escape_text(value)` | HTML-escapes text content. |
| `primitives.py` | `svg_open(width_mm, height_mm)` | SVG XML declaration and opening `<svg>` tag. |
| `primitives.py` | Shape primitives: `rect_mm()`, `circle_mm()`, `ellipse_mm()`, `polygon_mm()`, `polyline_mm()`, `line_mm()`, `path()` | Return SVG markup strings with mm→pt conversion. |
| `primitives.py` | `text_mm()`, `tspan()`, `multiline_text_mm()` | Text SVG markup with style attributes. |
| `primitives.py` | `image_mm()` | Image with base64 data URI from `asset_path`. Caches data URIs in `_DATA_URI_CACHE`. |
| `primitives.py` | `group()` | SVG `<g>` with id and inkscape label. |
| `primitives.py` | `grid_lines_mm()` | Debug grid overlay as path data. |
| `tokens.py` | `MM_TO_PT`, `PT_TO_MM` | Unit conversion constants (72/25.4, 25.4/72). |
| `tokens.py` | Page size tuples: `A4`, `A5`, `DL`, `US_LETTER`, `ROLLUP_850x2000` | (width, height) in mm. |
| `tokens.py` | Color palette: `WHITE`, `INK`, `INK_2`, `INK_3`, `INK_4`, `MUTED`, `MUTED_LIGHT`, `MUTED_SOFT`, `TEXT_SOFT`, `LINE`, `SOFT`, `ACCENT`, `ACCENT_DARK`, `BLUE_GLOW` | Hex color constants. |
| `tokens.py` | `DEFAULT_FONT_FAMILY`, `MONO_FONT_FAMILY` | Font stack strings. |

**Design Patterns:**
- **Dispatcher pattern:** `_render_element` switches on `ElementKind` enum.
- **Strategy pattern:** `_format_live_eligible_value` is parameterized by `RenderMode`; build mode emits concrete values, playground mode emits CSS variables only for safe live-tweak attributes.
- **Data URI caching:** `_DATA_URI_CACHE` in `primitives.py` avoids re-encoding images.
- **Fluent builder continuation:** `_normalize_svg_attrs` chains into `_format_live_eligible_value`.

**Design Patterns:**
- **Pipeline pattern:** `plan_export_targets` → `execute_export_plan` separates planning from execution.
- **Topological sort:** `plan_name()` recursively resolves preset dependencies.
- **Strategy (renderer):** `_write_raster_pdf` accepts a `render_svg` callback.
- **ZIP packaging:** IDML uses `zipfile.ZipFile` with structured internal paths.
- **ID allocation:** `_IdGenerator` ensures unique IDs across IDML elements.

### 2.7 `core/preview.py` — SVG Rasterization

| Function | Role |
|----------|------|
| `_render_svg_preview(svg_text, output_path, viewport)` | Main rasterization entry. Tries Playwright → CairoSVG → rsvg-convert → Inkscape. Raises `PreviewError` if all fail. |
| `render_preview_file(svg_path, output_path, viewport)` | Rasterizes a saved SVG file to PNG. |
| `render_raster(svg_path, spec_path, page_number, viewport)` | Renders to `cache.py` raster path. |
| `render_preview(...)` | Alias for `render_raster`. |
| `_default_viewport(svg_text)` | Extracts dimensions from SVG tag (`width`/`height` attributes or `viewBox`) and converts to pixels. Falls back to A4 (1191×1684 px at 96 DPI). |
| `_mm_to_px(value_mm)` | mm → px at 96 DPI. |
| `_pt_to_px(value_pt)` | pt → px at 96 DPI. |
| `PreviewError` | Rasterization failure. |

**Renderers (in priority order):**
1. **Playwright** — Chromium headless, `page.screenshot()`. Most accurate.
2. **CairoSVG** — `cairosvg.svg2png()`. Pure Python.
3. **rsvg-convert** — CLI tool. Good fidelity.
4. **Inkscape** — `--export-type=png`. Last resort.

## 3. Flow

### 3.1 End-to-End Build Flow

```
1. CLI / build system
   │
   ▼
2. loader.load_dsl_module("build.py")
   ├─ Clears remembered spec-local modules from previous loads
   ├─ Imports spec module as isolated Python module
   ├─ Resets auto-ids
   ├─ Sets chart spec base dir
   ├─ Remembers newly imported spec-local modules for next-load cleanup
   └─ Returns loaded module
   │
   ▼
3. Module's build() / collection / document attribute
   │
   ▼
4. render_pipeline.build_pages(module, config_dir)
   ├─ collection_from_module(module)
   │   └─ Validates module exposes DocumentCollection
   ├─ render_collection(collection)
   │   ├─ For each Document:
   │   │   ├─ _validate_document()
   │   │   │   ├─ Validates page uniqueness
   │   │   │   ├─ Validates export preset graph (no cycles, valid sources)
   │   │   │   └─ Validates element id uniqueness
   │   │   └─ _render_document_pages()
   │   │       ├─ For each Page (sorted by page_number):
   │   │       │   └─ _render_page()
   │   │       │       ├─ svg_open()
   │   │       │       ├─ _defs_block() for document defs
   │   │       │       ├─ _defs_block() for page defs
   │   │       │       ├─ For each Element: _render_element()
   │   │       │       │   └─ Dispatches on ElementKind
   │   │       │       │       └─ Calls primitive renderers from primitives.py
   │   │       │       └─ group_mm() closing tag
   │   │       └─ Returns list of RenderedPage
   │   └─ Returns BuildResult
   ├─ validate_document() warnings (non-token colors)
   └─ write_pages() if output_dir provided
   │
   ▼
5. BuildResult (pages: list[RenderedPage], documents: list[RenderedDocument])
   │
   ▼
6. Export pipeline (for each requested target)
   ├─ plan_export_targets(document, requested)
   │   └─ Topological sort of preset dependencies
   └─ execute_export_plan(rendered_document, plan, out_dir)
       ├─ For PAGE_SVG: write SVG files directly
       ├─ For PAGE_PNG: _render_svg_preview() each page → PNG
       ├─ For DOCUMENT_IDML: write_idml() → .idml ZIP
       └─ For DOCUMENT_PDF:
           ├─ PNG source: assemble PdfPages with PNG paths
           └─ SVG source: _render_svg_preview() each page → PNG → assemble PDF
```

### 3.2 Text Layout Flow

```
text() / wrapped_text() DSL call
    │
    ├─ _coerce_text_content() → normalized content
    ├─ _root_measurement_attrs() → {size_pt, letter_spacing}
    ├─ _flatten_text_runs() → list[_LayoutRun]
    │   └─ Handles strings, Markup, TextSpan, mixed sequences
    ├─ _tokenize_runs() → list[_WrapToken]
    │   └─ Tokenizes into: word / space / newline
    │
    ├─ measure_text(): sum token widths → TextMetrics
    └─ _wrap_layout():
        ├─ _LineBuilder state machine
        ├─ Breaks on width overflow or max_lines
        ├─ Handles ellipsis insertion
        └─ Returns _WrappedLayout(lines, TextMetrics)

Result:
    ├─ TextMetrics for measurement helpers
    └─ Element with structured lines (for wrapped_text)
```

### 3.3 Tweak Value Flow

```
Spec authoring:
    tweaks.group("theme", primary=tweaks.color(default="#c8a24a"))
    │
    ▼
tweak_context() active (set by loader.py or tests)
    │
    ▼
group("theme", primary=...)
    ├─ Creates TweakDeclaration(key="theme.primary", kind="color", ...)
    ├─ TweakRegistry.register(decl) → TweakValue(decl, registry)
    └─ Returns TweakGroup with TweakValue wrappers
    │
    ▼
TweakValue used in DSL (e.g., fill=theme.primary)
    │
    ▼
load_persisted_values("theme.toml")
    │
    ▼
validate_persisted_values(registry, raw)
    ├─ Type coercion per kind
    ├─ Range validation for numeric kinds
    └─ Returns (validated, diagnostics)
    │
    ▼
registry.apply_values(validated)
    │
    ▼
TweakValue.value now reads persisted value from registry.values
    │
    ▼
render._format_live_eligible_value() unwraps to primitive
    │
    ▼
SVG output with resolved color/size
```

## 5. Key Design Decisions

1. **Immutable model:** All domain types are `frozen=True` dataclasses. Elements are never mutated after construction.
2. **mm-based authoring:** DSL primitives use millimeter units internally. Conversion to SVG pt units happens only at render time in `primitives.py`.
3. **Element kind dispatch:** The `ElementKind` enum is the single dispatch point for both rendering and IDML export.
4. **Tweak lazy resolution:** `TweakValue` reads from registry on access, enabling persistence applied after spec load.
5. **Renderer fallback chain:** Preview uses Playwright → CairoSVG → rsvg-convert → Inkscape, each tried in order.
6. **IDML native editing:** IDML export maps Folio primitives to native InDesign page items rather than rasterizing, preserving editability.
7. **Auto-id generation:** `_element_id(kind, element_id)` auto-generates `rect_1`, `circle_2` style ids when `None` is passed.
8. **Chart PNG caching:** Chart PNGs are cached by content hash (`SHA-256[:16]`), so identical charts reuse files across builds.
